# Widget Cockpit V1

Implementation branch for the widget-first UI redesign.

Locked direction:
- Floating existing bot bust above a compact cockpit base.
- Four primary controls: Mic, Chat, Tools, More.
- Chat expands vertically from the widget.
- Coding tools attach as collapsible panels.
- Only one full bot is visible at a time; specialist work appears as activity chips.
- Rivet remains the primary coding specialist.
- Speaking feedback continues to use the existing robot speaker-grille equaliser driven by TTS output.
- Minimal macOS-inspired visual language with restrained sci-fi accents.
