# V1 Wireframe 07 — Luma creative panel

High-fidelity reference: [Specialist surfaces](../design-mockups/v1-core-surfaces.html#specialists).

Journey: describe idea → explore variants → inspect result → revise or save.

```text
┌────────────────────────────────┐
│ Luma · Creative studio  [×]    │
│ [Prompt…                  ]     │
│ [Reference] [Style] [Generate] │
├────────────────────────────────┤
│  [variant 1] [variant 2]       │
│  [variant 3] [variant 4]       │
│                                │
│ Luma: Which direction feels    │
│ most like the project?         │
│ [Edit] [Generate more] [Use]   │
└────────────────────────────────┘
```

Rules:

- Luma explains generation/editing progress and remains interruptible.
- References and output destinations are visible before an edit or save.
- Failed, filtered, unavailable, and partial results remain understandable.
- The user can remove references and discard outputs without affecting memory.
- Voice can refine the prompt while the panel stays focused.

QA: empty prompt, reference permission, generation progress, interruption, partial result, edit, save, discard, retry, and reduced-motion layout.
