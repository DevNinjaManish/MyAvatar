# MVP design reference

Approved visual mockups belong here. These files are implementation references, not feature proposals.

The final reference should show the same states covered by the wireframes and specify typography, color tokens, spacing, control states, focus treatment, and widget dimensions. Implementation should not begin for a surface until its design reference is approved.
