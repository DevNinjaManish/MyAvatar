# MVP product brief

## Product

MyAvatar is a small, local-first desktop companion that lives in a compact macOS widget. It lets a person start a focused conversation with one helpful character without opening a large dashboard or managing a complex agent system.

## MVP promise

Open the widget, choose a companion, type or speak a request, and receive a clear local response in a calm, dependable interface.

## Primary user

A Mac user who wants an approachable local AI companion for short everyday conversations and lightweight planning, with a visible character and a simple private-by-default runtime.

## Core user outcome

The user can complete one useful conversation quickly and understand what the app is doing at every point: ready, listening, thinking, responding, unavailable, or stopped.

## Product principles

- Widget first: the product is a compact companion surface, not a full-screen workspace.
- Stable before clever: predictable startup, input, response, stop, and recovery matter more than breadth.
- Local by default: runtime processing stays on the Mac in the MVP configuration.
- One clear path: avoid parallel panels, specialist modes, task agents, and hidden automation until the core loop is reliable.
- Honest state: never imply that a capability ran when it did not.
- Designed before implemented: wireframes and approved visual references are part of the product contract.

## MVP success signal

On a clean Mac setup, a user can launch the widget, choose a companion, send a typed message, receive a response, stop an in-progress response, and relaunch without losing the basic interface state or getting trapped in a broken mode.
